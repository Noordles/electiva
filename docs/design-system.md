# Electiva visual system

Student-requested direction: align with the Iraq Economic Observatory thesis workspace. Tokens were read from the local thesis checkout `program/assets/reader-theme.css`; the remote file path lookup returned404, so remote parity is not claimed.

| Token | Value | Use |
|---|---|---|
| Wine |#923951|Primary actions and hero focal surface|
| Wine soft |#452334|Selected navigation and badges|
| Wine ink |#f0c8d5|Secondary emphasis|
| Cyan |#79dce8|Wayfinding, focus rings, positive connection indicator|
| Canvas |#18151a|Page background|
| Surface |#231c23|Cards/forms/dialogs|
| Rail |#151216|Sidebar|
| Border |#483643|Quiet structural separation|
| Ink |#f3edf0|Primary text|
| Muted |#c6b9c2|Secondary text|

Adapted ideas: explicit borders, restrained wine panels, cyan navigation, system sans-serif plus occasional Georgia emphasis, consistent radii and spacing. No thesis data, branding claims or functionality is copied. SVG assets are local. Shared controls include buttons, labelled fields/selects, alerts, badges, loading/empty states, pagination and native dialog/confirmation wrappers. Native dialog supplies keyboard trapping/Escape/focus return; reduced-motion preferences are respected. M1 sample filters operate only on six illustrative client fixtures and are not the required persisted SQL catalog.
